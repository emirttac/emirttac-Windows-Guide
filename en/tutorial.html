Tutorial: Step by Step

How to use: This page gives a short workflow for readers who want to apply the guide's sections in order. Each step's details are in the linked section. Do not move on until the output of the current step has been checked.

Prerequisites: An elevated Command Prompt, enough free space on the working drive, and a backup of the original media. Paths such as C:\Mod and placeholders such as <N> are examples; replace them with values from your own media.

Warning: Do not apply this workflow to a real device or distribution media before testing it in a virtual machine. Microsoft Edge and WebView2 removal, disabling security features, and activation bypass steps are not part of this workflow (see 1 and 10.4).

Step 1: ADK and oscdimg installation

  • Download the Windows ADK from Microsoft's Windows ADK installation page and install only the Deployment Tools feature. oscdimg.exe ships with it. For version selection, see 3.3.
  • After installation, note the path to oscdimg.exe. It is usually in the ...\Deployment Tools\amd64\Oscdimg\ folder.

Step 2: Preparing the working environment

  • Create the C:\Mod folder and add two folders inside it: Gecici (mount directory) and Medya (ISO contents). Avoid spaces and non-ASCII characters in paths, and do not use protected locations such as Documents (3.1).
  • Mount the Windows 11 ISO (right-click > Mount) and copy all of its contents to C:\Mod\Medya.
  • Remove the read-only attribute from the copied install.wim and take ownership of it. In an elevated Command Prompt:
attrib -r "C:\Mod\Medya\sources\install.wim"
takeown /F "C:\Mod\Medya\sources\install.wim"
icacls "C:\Mod\Medya\sources\install.wim" /grant Administrators:F
  • Copy install.wim to C:\Mod\install.wim as the working copy. The original stays in C:\Mod\Medya\sources as a backup; do not delete it until Step 7.

Step 3: Finding the WIM index and mounting

  • Get the index list:
dism /Get-ImageInfo /ImageFile:"C:\Mod\install.wim"
  • In the output, find the Index number of the target edition. Take it only from this media's output; an index from another media may not match (5.2).
  • Mount the image, replacing <N> with the index you found:
dism /Mount-Image /ImageFile:"C:\Mod\install.wim" /Index:<N> /MountDir:"C:\Mod\Gecici"
  • Verify the mount: dism /Get-MountedImageInfo.

Step 4: Listing provisioned package names

  • List the provisioned AppX packages in the mounted image:
dism /Image:"C:\Mod\Gecici" /Get-ProvisionedAppxPackages
  • Copy the PackageName values of the packages you want to remove. Package names change with version and language, so use this output as the source; names from another version will not match (10.3).

Step 5: Removing the selected provisioned packages

  • Choose the packages to remove by group: communication apps, news and feedback apps, extra apps preinstalled by Microsoft, and game leftovers. In each line, use the full package name from Step 4; do not use wildcards.
  • Repeat the template below for each package you selected:
dism /Image:"C:\Mod\Gecici" /Remove-ProvisionedAppxPackage /PackageName:<FULL_PACKAGE_NAME_1>
dism /Image:"C:\Mod\Gecici" /Remove-ProvisionedAppxPackage /PackageName:<FULL_PACKAGE_NAME_2>
  • Removing provisioned packages only affects users created later; existing users' packages are not affected (10.1).
  • Do not touch the shell, the Store infrastructure, or other system components (10.3).

Step 6: Setting the default user profile (optional)

  • SetupComplete.cmd runs as the Local System account, so HKCU writes inside it do not reach the new user. Write per-user settings to the Default profile hive instead (9.1, 8.2).
  • Load the default profile hive under a temporary name:
reg load HKLM\MODDEFAULT "C:\Mod\Gecici\Users\Default\NTUSER.DAT"
  • Write the values you want. The lines below are examples only; for the meaning of each value, see the table in 9.2:
reg add "HKLM\MODDEFAULT\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize" /v AppsUseLightTheme /t REG_DWORD /d 0 /f
reg add "HKLM\MODDEFAULT\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize" /v SystemUsesLightTheme /t REG_DWORD /d 0 /f
reg add "HKLM\MODDEFAULT\Software\Microsoft\Windows\CurrentVersion\Explorer\HideDesktopIcons\NewStartPanel" /v "{20D04FE0-3AEA-1069-A2D8-08002B30309D}" /t REG_DWORD /d 0 /f
reg add "HKLM\MODDEFAULT\Software\Microsoft\Windows\CurrentVersion\Explorer\HideDesktopIcons\NewStartPanel" /v "{645FF040-5081-101B-9F08-00AA002F954E}" /t REG_DWORD /d 0 /f
reg add "HKLM\MODDEFAULT\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v TaskbarDa /t REG_DWORD /d 0 /f
reg add "HKLM\MODDEFAULT\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" /v TaskbarMn /t REG_DWORD /d 0 /f
  • Close any open Registry Editor window, then unload the hive. If the hive stays open, unloading fails (9.3):
reg unload HKLM\MODDEFAULT

Step 7: Committing changes and putting install.wim back

  • Close File Explorer windows and any open files under C:\Mod\Gecici. Unmounting can fail for these reasons (14.2).
  • Run the listing command from Step 4 again; the packages you removed should no longer appear.
  • Commit the changes and unmount the image:
dism /Unmount-Image /MountDir:"C:\Mod\Gecici" /Commit
  • If an error occurs, review %WINDIR%\Logs\Dism\dism.log before considering /Discard, which throws away the changes (14.1).
  • Move the original C:\Mod\Medya\sources\install.wim to a backup location, then copy the modified C:\Mod\install.wim into C:\Mod\Medya\sources.

Step 8: Creating the ISO

  • In an elevated Command Prompt, build the ISO. If oscdimg.exe is not on the PATH, use the full path you noted in Step 1:
oscdimg -m -o -u2 -udfver102 -bootdata:2#p0,e,b"C:\Mod\Medya\boot\etfsboot.com"#pEF,e,b"C:\Mod\Medya\efi\microsoft\boot\efisys.bin" "C:\Mod\Medya" "C:\Mod\Custom.iso"
  • Because install.wim is larger than the 4 GiB limit, UDF (-u2) is required (7.3).
  • Record the SHA-256 hash of the ISO: Get-FileHash -Algorithm SHA256 "C:\Mod\Custom.iso" (7.4).

Step 9: Testing in a virtual machine

  • Attach the ISO to a UEFI-capable virtual machine (such as a Hyper-V Generation 2 VM) and boot from it. Test BIOS and UEFI boot separately (7.4).
  • Check the logs during and after setup: C:\Windows\Panther\UnattendGC\setupact.log (14.1).
  • Do not write an ISO that fails testing to physical media. For troubleshooting, see the matrix in 14.2.
