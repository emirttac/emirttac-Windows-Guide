Windows Customization Guide by emirttac

Windows Customization Guide by emirttac

Scope: This guide covers inspecting official Windows 11 installation media, servicing its images offline, and repackaging the media with Microsoft tools: DISM, the DISM PowerShell module, reg.exe, oscdimg, and Windows Setup. Third-party image editors are outside its scope.

Target: Windows 11, version 26H2 (build 26300), and supported earlier versions Last reviewed: November 22, 2026

This is an independent guide, not a Microsoft publication or endorsement. Microsoft Learn is the primary technical reference. Windows is a trademark of Microsoft Corporation.

1. Scope and Limitations

The guide covers:

  • Installation media structure and WIM/index architecture
  • Offline image servicing (mounting, modifying, saving, or discarding)
  • Creating bootable ISOs and choosing between UDF and ISO 9660
  • Windows Setup scripts and answer file mechanisms
  • Validation, logs, and troubleshooting

It does not cover:

  • Bypassing system requirement checks
  • Modifying Windows activation mechanisms
  • Disabling security features such as Secure Boot, BitLocker, Windows Defender, and memory integrity
  • Removing Microsoft Edge and WebView2 Runtime (see 10.4)
  • Third-party image editing tools
